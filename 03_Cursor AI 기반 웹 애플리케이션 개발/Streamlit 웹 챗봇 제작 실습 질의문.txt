[Streamlit 웹 챗봇 제작 실습 질의문]

프로젝트 폴더명 : Streamlit_Web_Chatbot

- Streamlit Web Chatbot  만들기 질의문
Streamlit을 사용해서 간단한 웹 챗봇 서버를 만들어줘.
조건은 다음과 같아 :
1. 현재 경로에서 채팅 UI(입력창, 버튼, 채팅창 영역)를 보여준다.
2. OpenAI API 최신 버전 스타일 코드로 만들어주고 모델도 "gpt-4o-mini'를 사용하도록 해줘. 
3. API 키를 C:\env\ 경로의 .env 파일에서 환경변수로 읽어와서 사용하도록 구현해줘
4. 사용자가 메시지를 입력하면 서버가 OpenAI API에 전달하고, 모델의 응답을 받아 채팅창에 표시한다.
5. 실행에 필요한 requirements.txt 파일도 함께 만들어줘.
