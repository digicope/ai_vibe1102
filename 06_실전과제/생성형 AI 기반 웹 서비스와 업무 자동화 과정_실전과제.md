# 실전 과제

## AI 기반 지능형 업무 문서 분석 및 보고서 생성 서비스

-   실습 시간: 3시간
-   실습 형태: 개인 실습
-   개발 방식: Cursor AI 바이브 코딩

## 1. 과제 목표

기업에서 사용하는 업무 문서(PDF, TXT 등)를 업로드하면 생성형 AI가 문서
내용을 분석하고 핵심 내용을 요약하며, 사용자의 질문에 답변하고 최종 업무
보고서를 생성하는 웹 애플리케이션을 개발한다.

Cursor AI를 활용한 바이브 코딩 방식으로 개발하며, OpenAI API를 연동하여
실제 동작하는 AI 서비스를 구현한다.

## 2. 개발 환경

-   개발 도구: Cursor AI
-   프로그래밍 언어: Python
-   웹 프레임워크: Streamlit
-   생성형 AI: OpenAI API
-   주요 라이브러리: `openai`, `streamlit`, `pypdf`, `python-dotenv`
-   환경변수: `.env` 파일을 활용한 API Key 관리

## 3. 주요 구현 기능

### ① 문서 업로드 기능

-   PDF 또는 TXT 파일 업로드
-   업로드한 문서의 텍스트 추출
-   문서 내용 및 파일명 표시

### ② AI 문서 분석 및 요약

-   OpenAI API를 활용한 문서 내용 분석
-   핵심 내용 5개 항목 요약
-   주요 키워드 및 중요 정보 추출
-   문서의 전체적인 내용과 목적 설명

### ③ AI 문서 질의응답

-   업로드한 문서에 대한 질문 입력
-   AI가 문서 내용을 기반으로 답변
-   문서에 없는 내용은 추측하지 않고 확인할 수 없다고 답변하도록 구현

### ④ AI 업무 보고서 생성

-   문서 분석 결과를 활용한 업무 보고서 생성
-   보고서 구성: 개요, 주요 내용, 분석 결과, 결론 및 제안
-   생성된 보고서를 화면에 출력
-   TXT 파일로 다운로드 기능 제공

### ⑤ 웹 서비스 UI 구성

-   사이드바에 파일 업로드 기능 배치
-   메인 화면에 문서 요약 및 분석 결과 표시
-   질의응답 채팅 인터페이스 구성
-   보고서 생성 및 다운로드 버튼 구현

## 4. 개발 요구사항

-   Cursor AI를 활용하여 전체 프로그램을 구현한다.
-   OpenAI API를 실제로 연동한다.
-   API Key는 소스 코드에 직접 작성하지 않고 `.env` 파일에서 불러온다.
-   기능별로 코드를 구분하여 유지보수가 가능하도록 작성한다.
-   예외 처리를 통해 파일 업로드 및 API 호출 오류에 대응한다.
-   실제 실행 가능한 웹 애플리케이션을 완성한다.
